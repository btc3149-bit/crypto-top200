一、本页说明什么

本页说明本站在您访问时会处理哪些数据、经由哪些系统、用于什么目的，以及您如何屏蔽其中的统计部分。本站是一个公开的行情榜单页面：无账号系统、无广告、无付费功能。

二、一句话总览

本站无账号、无广告、无 Cookie 统计；只有两条数据流：聚合流量统计（Cloudflare Web Analytics，尚未启用，见第三节）与榜单数据代理（CoinGecko 行情经本站服务端转发，见第四节）。

三、数据流一 · 网站流量统计（Cloudflare Web Analytics，尚未启用）

本站计划使用 Cloudflare Web Analytics 做聚合流量统计，目前尚未启用。启用后它的数据流如下（按 Cloudflare 官方口径）：页面加载时从 static.cloudflareinsights.com 加载一个轻量脚本（beacon），把本次浏览的聚合信号回传本站的 /cdn-cgi/rum 路径。

采集项仅为聚合统计所需：页面路径、来源站（referrer）、国家/地区、设备/浏览器/操作系统粗分类、页面加载性能与 Core Web Vitals（LCP/INP/CLS 等）。它无 Cookie、无本地存储、无指纹识别、不跨站追踪、不记录 URL 查询串。数据留存口径：未采样的原始 beacon 数据保留 7 天，之后聚合保存，仪表盘可查过去 6 个月。本站能看到的只是聚合报表，看不到单个访客的记录。用途仅为了解访问量与页面性能，不用于广告或画像。

另请知悉读数边界：广告拦截器会屏蔽该脚本域名，部分网络环境下脚本也可能加载失败，这些访问不会计入统计——统计数字只看趋势，不代表全部访客。

四、数据流二 · 榜单数据代理（CoinGecko）

榜单的实时行情来自 CoinGecko。您的浏览器不直连 CoinGecko：浏览器只请求本站的同源接口 /api/board，由本站服务端函数向 CoinGecko 拉取行情后转发给您。因此 CoinGecko 一侧看到的是本站服务器发出的请求，而不是您的身份信息。

按服务端函数的实际代码：行情结果在服务端缓存 120 秒，缓存期内多人访问共用同一份数据；上游故障时回退最近一次成功数据并明确标注为缓存/快照状态，不会把旧数据冒充实时。本站服务端函数不记录、不存储访客的 IP 地址，其运行日志仅包含错误类型、上游状态码与耗时。本站不把榜单请求数据用于画像，也不出售或共享给任何第三方。

五、数据流三 · 浏览器本地存储

本站自身不设置任何 Cookie，这也是本站不弹 Cookie 横幅的原因。

若您使用本站的自选/收藏功能，该功能会使用浏览器 localStorage（键名以实际上线版本为准，预定为 top200.watchlist.v1）把您选中的币种只保存在您本机浏览器里，不上传到任何服务器；清除浏览器站点数据即可删除。未使用该功能时，不写入该键。

六、本站不收集什么

  • 不收集姓名、邮箱、手机号等身份信息；无注册、无登录。
  • 无广告，无第三方营销追踪；明确不使用 Google Analytics 类带 Cookie 的统计工具。
  • 不做浏览器指纹识别。
  • 不出售或共享个人数据——本站本身就不持有个人数据。

七、屏蔽方法与不影响使用

统计启用后，如您不希望被计入统计，可用广告拦截器屏蔽 cloudflareinsights.com，或在浏览器中全局拦截第三方脚本。屏蔽后本站全部功能（榜单、自选）照常可用，仅该次访问不计入统计。
