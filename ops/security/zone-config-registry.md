## 登记条目

### Z-01 `Access-Control-Allow-Origin: *`（来源未定位的跨域放开）

| 项 | 内容 |
|---|---|
| 配置内容 | 响应头 `Access-Control-Allow-Origin: *`，出现在本站响应上 |
| 来源口径 | 安全路 2026-11-13 实查（PHASE4_REVIEW.md F4-31）；本续写与评审均未复测控制台侧 |
| 本轮复核（2026-11-13，只读） | 线上响应头实测仍在位：`https://top200.oppcal.com/`、`/data/coins.json`、`/privacy/` 以及 `https://crypto-top200.pages.dev/` 四处 `curl -sI` 均返回 `Access-Control-Allow-Origin: *`（即同时覆盖自定义域与 pages.dev 域、覆盖静态与数据路径）。仓库内 grep 该头零命中（`public/_headers`、`ops/headers/`、Functions 代码均无；唯一提及是 PHASE2_PLAN §18 对 `/data/*` 分组的定版说明「**不开** Access-Control-Allow-Origin」）。Zone 只读核查：Page Rules 为空；规则集（rulesets）仅有 Cloudflare 托管规则集，未见自定义的响应头改写（`http_response_headers_transform`）规则集——**常见来源均已排除后仍未定位其注入点**，不排除 Pages 平台侧行为或其他控制台设置，须站长在控制台确认 |
| 与既定口径的冲突 | PHASE2_PLAN §18 定版为不开 ACAO（数据只供本站同源 fetch，跨源需求走人工评估）；现状与定版相反且无任何变更记录 |
| 风险 | ①「仓库是唯一事实源」假设被打破：改 `_headers` 覆盖不了这一层，代码审查得出的 CORS 结论与线上实际不一致；②任意网站可跨源读取本站公开响应（本站数据本身公开，实际数据泄露风险低，但 `/api/board` 等接口的跨源可读面与定版意图不符）；③未来排查跨域问题会先在错误的位置找原因；④可能影响 Observatory 的 CORS 类评估项（与 `security-baseline.md` §3.3 的未决残项关联） |
| 候选处置（二选一） | **A. 收编进仓库管理**：确认无跨源业务需求后，定位并移除 Zone / 平台侧注入点；如确需保留跨源读取，改由 `public/_headers` 对明确路径组显式声明，使其进入 gen-headers / smoke-headers 的管理与断言范围。**B. 保留并登记用途**：确认存在实际用途（如某外部消费者直读数据）后在本条目补记用途、依赖方与复核日期，Zone 侧原样保留，本条目即为其唯一留痕 |
| 状态 | **待站长在控制台确认用途与注入点后二选一**（本轮未做任何 Zone 变更；确认前维持现状并以本条目为留痕） |

### Z-01 处置记录（2026-11-13，站长授权助手裁决执行）

- **裁决：选 A（收编进仓库管理）。** 理由：①§18 定版为不开 ACAO，且全站排查无任何跨源消费者（数据只供本站同源 fetch、`/api/*` 为同源调用），B 方案所需的「实际用途」不存在，保留等于把与定版相反的状态永久化；②A 的核心目标是消除不确定性——注入点定位与显式声明都可验证，B 只登记不确定性本身。
- **注入点定位（新证据）**：Functions 响应（`/api/board`、`/api/health`）从不带此头，静态路径与 404 回落路径带头，且自定义域与 pages.dev 域、production 与 preview 部署一致出现——Zone 层规则只作用于自定义域 zone、不可能覆盖 pages.dev，故注入点定性为 **Pages 平台静态资源服务层的默认行为**，非控制台手工配置。此前「注入点未定位」的不确定性就此消除。
- **执行**：`ops/headers/_headers.tmpl` 的 `/*` 组新增显式声明 `Access-Control-Allow-Origin: https://top200.oppcal.com`（收编进 gen-headers 生成与 smoke-headers 断言范围）。先 preview 实测：四条路径均为**单条**该头且值为声明值（平台 `*` 被仓库声明替换而非叠加；preview 别名根路径首测的 `*` 为上一部署 SWR 缓存，复测即为声明值）；再生产部署 `8dff02de`（2026-11-13），冒烟 6/6、探针 7/7、HC2 已报到。生产四路径复测均为单条声明值，通配 `*` 已消除。同源 fetch 不受 ACAO 约束、`/api/*` 不走 _headers，功能零影响。
- **状态**：**已收编（2026-11-13，部署 `8dff02de`）**。月度复核时按登记规则核对：若该头再次变为 `*` 或消失，按 F4-31 同类问题上报。
